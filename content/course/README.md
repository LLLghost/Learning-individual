# Источник нового маршрута

`manifest.json` задаёт постоянные идентификаторы, порядок, предпосылки, среду
практики и задания каждого урока. `lessons/*.html` — редактируемое содержание.
`assessments.json` хранит задания; `ui/` — общий интерфейс. Сборка генерирует
сайт, поиск и переносимую книгу из этих источников.

Цель курса — понимание и эксплуатация серверной инфраструктуры. `infrastructure.json`
задаёт конечный результат, десять этапов лаборатории, материалы и проверки, а
также индивидуальные роли и задания на перенос всех 82 уроков. Страница с заметкой
используется только в первых опытах и подходящих технических примерах.
`/laboratory/`, план Markdown и печатная книга строятся из этой же карты.

Урок содержит шесть обязательных блоков: goal, explain, example, guided,
independent, reflection. Новое понятие объясняется до действия. Команда требует
контекста, прав, цели, ожидаемого результата и поведения при отклонении.
Встроенные данные не выдаются за исполнение действия на ВМ.

В блоках depth находятся переработанные технические разборы; прежние заголовки
сопоставлены с ними через постоянные якоря и ссылки в архив. Исходная полная проза
сохранена в архиве v6. `reviewed:false` нельзя заменять на true результатом
проверки существования текста.

Реестр исходных глав, модулей, разделов и проверок расположен в
`quality/curriculum-map.json`. При редактуре сохранять привязку к объяснению
либо менять её после чтения вопроса и нового объяснения. Соблюдать различие
между уровнем главы bNN и академическим модулем chNN.

`work/author-course.mjs` — первоначальная заготовка переноса, не штатный
инструмент редактуры. Повторный запуск перезапишет ручные правки: не использовать
его после начала вычитки. Сборка `npm run build` исходники уроков не меняет.

Редакторские источники от 27 октября находятся в `editorial/`: основные цепочки,
предметные схемы, `depth.py` с новыми углублениями 76 уроков и явные решения по
530 вопросам. Отрисовка — `npm run editorial:render`; повторный запуск должен
быть воспроизводимым. Полные старые тексты остаются в архиве, а не внутри нового
объяснения. `quality/depth-map.json` сохраняет соответствие прежних заголовков
новым темам и 1312 якорей. Это тематическое объединение, а не 1312 отдельно
переписанных уроков. Авторская приёмка зафиксирована хешами в
`quality/lesson-rewrite-review.json`; `npm run validate:editorial` выявляет
изменение принятого текста. Перегенерация сама не принимает изменённый материал.

Переработка от 28 октября: `editorial/foundation.json` — шесть вводных уроков;
`foundation-assessments.json` — шесть вопросов с прямыми объяснениями;
`infrastructure-overrides.json` — изменения методов, карты стенда и итоговых работ.
`apply-course-context.py` вставляет авторские роли и перенос в исходные фрагменты.
Его повторный запуск заменяет только собственные маркеры. Технические части
остальных уроков не переписываются ради смены примера. Сверка сохранена в
`quality/infrastructure-rewrite-review.json` и проверяется `check-infrastructure.mjs`.
Проверка структуры не подтверждает самостоятельную итоговую лабораторию.
