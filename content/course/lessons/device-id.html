Связать физическое устройство с драйвером

Результат: Связать имя интерфейса с устройством и драйвером через sysfs.

Объект: Страница заметок и выделенные ресурсы текущего опыта.

Разберёмся до действия

Имя eth0 или enp… — представление сетевого интерфейса, а не достаточное описание физического порта. sysfs показывает связи объектов ядра; ссылка device/driver помогает узнать привязанный драйвер. MAC может быть изменён или виртуализирован, поэтому его используют вместе с топологией и карточкой оборудования. Один адаптер может предоставлять несколько функций или виртуальных интерфейсов. Loopback не обязан иметь физическое device/driver.

Среда и права: В учебном Linux-госте обычным пользователем; sudo требуется только для явно указанных изменений. Данные примера можно разбирать без стенда.

Разобранный пример

Команды примера; переменные WORK и NS задаются в инструкции практики ниже:

ip -br link
readlink -f /sys/class/net/eth0/device/driver

Ожидаемый результат: Имя eth0 в своей среде нужно заменить фактическим. Для аппаратного или виртуального устройства видна ссылка на драйвер, если она представлена; для lo её может не быть.

Сопоставь наблюдение с описанным механизмом. Вывод относится к проверенному объекту и условиям опыта.

При отклонении: При несовпадении результата сохрани фактический вывод, проверь предпосылки и остановись перед дальнейшими изменениями. Не подменяй наблюдение ожидаемым текстом.

Прогноз и опыт с поддержкой

Предскажи связь интерфейса с PCI-функцией. Подготовь device-id, перечисли интерфейсы и ссылки на драйверы, сохрани observation.txt. Отметь виртуальные интерфейсы отдельно.

Самостоятельная задача

После новой подготовки повтори без запоминания eth0. Найди интерфейс по карте среды и сопоставь с sysfs, не переименовывая его ради совпадения примера.
