Проверить адрес и маршрут IPv6

Результат урока: Проверить адрес и маршрут IPv6 и подтвердить вывод наблюдением.

Сначала разберёмся

IPv6 использует адреса другого формата и соседское обнаружение вместо ARP. У интерфейса может быть несколько адресов с разными областями действия. Наличие IPv4-связи не доказывает доступность IPv6. Проверяют выбранный адрес, маршрут и фактический протокол обращения.

Разобранный пример

Имя возвращает IPv4 и IPv6. Один путь работает, второй не настроен. Пользовательское поведение зависит от выбора адреса приложением.

Где и от чьего имени: На ВМ прочитай существующее состояние без отключения IPv6; отметь, настроена ли маршрутизация в стенде.

Цель команды: получить наблюдение, описанное ниже. Команды с sudo требуют прав администратора учебной ВМ; остальные выполняются обычным пользователем.

ip -6 address; ip -6 route; ip -6 neigh

Ожидаемый результат: Адреса, маршруты и IPv6-соседи. Это описание вида результата; имена и значения сверяют со своей машиной.

Если результат отличается: сохрани вывод и код ошибки, проверь имя машины, наличие инструмента и права. До выяснения причины не переходи к изменяющим действиям.

Опыт с поддержкой

На ВМ прочитай существующее состояние без отключения IPv6; отметь, настроена ли маршрутизация в стенде.

До действия запиши, что ожидаешь увидеть и почему. После сравни результат с прогнозом, сохрани факты и обозначь, что они ещё не доказывают.

Подробные механизмы, команды и дополнительные примеры

Здесь сохранены технические разборы предыдущей редакции. Они ещё проходят сверку с новым уроком; статус редакционной приёмки указан в карте качества.

Действия

Сравнить MTU интерфейсов и найти границу размера пакета, который ещё проходит. Ключ здесь — флаг -M do (не фрагментировать) и явный размер данных:

ip link show
ping -M do -s 1372 -c2 10.20.30.15    # 1372 + 28 = 1400 байт
ping -M do -s 1472 -c2 10.20.30.15    # 1472 + 28 = 1500 байт
tracepath 10.20.30.15
tcpdump -ni any 'icmp[icmptype] == 3'

Получено:

# ping -M do -s 1372 ...   2 packets transmitted, 2 received
# ping -M do -s 1472 ...   2 packets transmitted, 0 received
# tracepath 10.20.30.15
 1?: [LOCALHOST]      pmtu 1500
 2:  10.20.30.1       asymm 1  1.204ms pmtu 1400
# tcpdump: тишина — ни одного ICMP type 3
