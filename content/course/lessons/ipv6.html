Проверить адрес и маршрут IPv6

Результат: Настроить и проверить прямой IPv6-путь в изолированном сегменте.

Объект: Страница заметок и выделенные ресурсы текущего опыта.

Разберёмся до действия

IPv6 использует 128-битные адреса. Префикс задаёт сеть, а соседей ищет Neighbor Discovery через ICMPv6, не ARP. У интерфейса может быть несколько адресов, включая link-local. Для link-local вне неоднозначного контекста нужен идентификатор интерфейса. В IPv6 нет IPv4 broadcast; бездумная блокировка ICMPv6 ломает необходимые механизмы. Наличие IPv4-связи не подтверждает IPv6, и наоборот.

Среда и права: В учебном Linux-госте обычным пользователем; sudo требуется только для явно указанных изменений. Данные примера можно разбирать без стенда.

Разобранный пример

Команды примера; переменные WORK и NS задаются в инструкции практики ниже:

sudo ip -n "$NS-a" -6 address
sudo ip -n "$NS-a" -6 route get 2001:db8::2

Ожидаемый результат: После назначения 2001:db8::1/64 и ::2/64 двум узлам маршрут идёт через eth0. Префикс 2001:db8::/32 предназначен для документации и здесь используется в изоляции.

Сопоставь наблюдение с описанным механизмом. Вывод относится к проверенному объекту и условиям опыта.

При отклонении: При несовпадении результата сохрани фактический вывод, проверь предпосылки и остановись перед дальнейшими изменениями. Не подменяй наблюдение ожидаемым текстом.

Прогноз и опыт с поддержкой

Подготовь ipv6. Предскажи отсутствие нужного адреса до изменения; добавь адреса только в два namespace. В опыте допускается nodad для немедленной проверки, а на настоящей сети DAD не отключают без причины.

Самостоятельная задача

Откати работу и повтори. Покажи IPv6-маршрут и успешный ping -6 независимо от IPv4. Объясни, почему не надо искать ARP-запись IPv6-соседа.

Действия

Сравнить MTU интерфейсов и найти границу размера пакета, который ещё проходит. Ключ здесь — флаг -M do (не фрагментировать) и явный размер данных:

ip link show
ping -M do -s 1372 -c2 10.20.30.15    # 1372 + 28 = 1400 байт
ping -M do -s 1472 -c2 10.20.30.15    # 1472 + 28 = 1500 байт
tracepath 10.20.30.15
tcpdump -ni any 'icmp[icmptype] == 3'

Получено:

# ping -M do -s 1372 ...   2 packets transmitted, 2 received
# ping -M do -s 1472 ...   2 packets transmitted, 0 received
# tracepath 10.20.30.15
 1?: [LOCALHOST]      pmtu 1500
 2:  10.20.30.1       asymm 1  1.204ms pmtu 1400
# tcpdump: тишина — ни одного ICMP type 3
