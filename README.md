# Серверная инфраструктура

Многостраничный университетский курс для самостоятельного изучения серверной инфраструктуры: Linux, сети, серверное оборудование, хранение данных, автоматизация, контейнеры и firmware.

Публичная версия: <https://server-infrastructure-university-ru.alexghost2011.chatgpt.site/>

## Возможности

- 28 теоретических глав и 28 практических модулей;
- автоматизированная проверка знаний и сохранение прогресса в браузере;
- светлая и тёмная темы;
- личные заметки, сохранение и копирование цитат;
- цветные маркеры с восстановлением после перезагрузки и отменой выделения;
- внутренние ссылки между главами, практикумом и справочником.

## Локальный запуск

```powershell
pnpm install
pnpm build
python -m http.server 4175 --bind 127.0.0.1 --directory build
```

После запуска откройте <http://127.0.0.1:4175/>.

## Проверка

```powershell
pnpm validate
node --check build/assets/site.js
```

Генератор сайта находится в `scripts/build-static.mjs`, исходный учебник — в `public/course.html`. Каталог `build/` создаётся автоматически и не хранится в Git.

Заметки, результаты проверок и настройки интерфейса сохраняются в `localStorage` текущего браузера.
