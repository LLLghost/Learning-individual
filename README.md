# Серверная инфраструктура

Курс для самостоятельного изучения серверной инфраструктуры: Linux, сети, оборудование, хранение данных, автоматизация, контейнеры и прошивки. Один исходный файл превращается сборкой в статический сайт с учебным кабинетом, тренажёрами и проверкой практических работ.

> **Сделано с помощью ИИ.** Текст учебника, генератор сайта, интерфейс и инструменты проверки написаны с помощью [Claude Code](https://claude.com/claude-code).

## Что внутри

| | |
| --- | --- |
| Текст | 5 вводных уроков, 34 главы (00–33), 37 академических модулей, ~123 000 слов |
| Практика | 74 работы практикума; у 24 из них есть автоматическая проверка |
| Проверка знаний | 111 заданий и 37 сценариев по 4 шага, интервальное повторение слабых тем |
| Справочник | 280 терминов, приложения с командами, шаблонами runbook и первоисточниками |
| Инструменты чтения | заметки, цитаты, цветные маркеры, поиск по всему курсу, светлая и тёмная темы |

Всё состояние хранится в `localStorage` браузера и никуда не отправляется; страница «Маршрут» собирает его в один файл резервной копии.

Сайт работает без интернета: страницы отдаются из кэша браузера, а кнопка на странице «Маршрут» кладёт туда сразу весь курс вместе с поиском.

## Чем этот курс отличается

- **Вопрос до чтения.** В каждой главе ответ даётся прежде объяснения: попытка ответить до чтения улучшает то, что останется после, и неверная попытка работает не хуже верной.
- **Свободное воспроизведение.** В конце главы — пересказ по памяти и только потом сверка со списком тем: узнавание готовых вариантов легче припоминания и завышает ощущение владения темой.
- **Три проверки, и каждая своя.** Мини-тренажёр в конце главы спрашивает, прочитана ли глава; задания модуля в кабинете — применяется ли механизм к незнакомой ситуации; работа практикума — доводится ли наблюдение до доказанной причины там, где готового решения нет. Вопросы у них разные: первый ярус не показывает того, что оценивает второй.
- **Двухъярусная проверка.** У задания на механизм спрашивают не только ответ, но и рассуждение, которое к нему ведёт. Оба яруса — до любого вердикта, и задание засчитано только когда верны оба: один вариант из четырёх угадывается, механизм — нет.
- **Калибровка уверенности.** Уровень (догадка / склоняюсь к ответу / знаю) заявляется до проверки и после результата не меняется.
- **Прогресс подделать нельзя.** Отметка ставится только по факту решённой проверки. То, что читатель отмечает себе сам, ничего не засчитывает — это осознанное решение, а не недоделка.

## Автоматическая проверка работ практикума

Скрипт готовит задание — выдаёт набор данных или вносит неисправность на учебный стенд, — читатель решает, скрипт собирает факты в файл, а учебный кабинет сверяет их и выносит вердикт.

Сверка идёт в браузере, а не в скачанном скрипте, и ожидаемые значения лежат хешами. Это защита от подглядывания, а не от подделки: файл отчёта лежит на машине читателя. Смысл в другом — чтобы вписать правдоподобные факты, нужно знать внесённый вариант и вид подтверждённой гипотезы, то есть почти всё решение.

Скрипт, вносящий неисправность, отказывается работать без метки `/etc/course-lab-stand`, не трогает управляющую сеть, умеет `--dry-run` и откат.

## Локальный запуск

Сборке и проверке нужен только Node со стандартной библиотекой — `pnpm install` для них не требуется.

```bash
node scripts/build-static.mjs
python3 -m http.server 4175 --directory build
```

Откройте <http://127.0.0.1:4175/>.

## Проверка

```bash
node scripts/validate-site.mjs
node --check build/assets/site.js
```

Отдельного тестового прогона нет: `scripts/validate-site.mjs` и есть спецификация — он ловит то, что не видно ни в сборке, ни в разметке.

## Публикация

`.github/workflows/pages.yml` собирает сайт, прогоняет проверку и публикует при push в `main`; базовый путь для страниц проекта он выбирает сам. Включается в **Settings → Pages → Source → GitHub Actions**.

Собрать вручную для подкаталога:

```bash
BASE_PATH=/Learning-individual node scripts/build-static.mjs
```

## Устройство репозитория

| Путь | Назначение |
| --- | --- |
| `public/course.html` | **Исходный учебник целиком.** Единственный источник содержания. |
| `public/reference-terms.json` | Дополнение к глоссарию и варианты написания для поиска по выделенному тексту. |
| `scripts/build-static.mjs` | Генератор: режет учебник на 47 маршрутов, собирает навигацию, поиск, кабинет, CSS и JS. |
| `scripts/validate-site.mjs` | Проверка собранного сайта. |
| `scripts/text-nodes.mjs`, `scripts/study-strings.mjs` | Правка прозы и банка заданий без риска повредить разметку и ответы. |
| `build/` | Результат сборки, в Git не хранится. |
