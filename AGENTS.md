# Практический курс: текущая переработка

Пользователь утвердил полную переработку учебника для начинающего: объяснение до
нового термина и действия, разобранный пример, поддержанный опыт, самостоятельная
задача и повторение. Формат — сайт и настоящий Linux/Proxmox-стенд, переход к
терминалу постепенный. Сохранить охват 34 глав, 37 углублений и 530 прежних оценок.

- Основной новый источник: `content/course/manifest.json` и его HTML-фрагменты.
  Прежний `content/manifest.json` описывает только архив v6.
- `npm run build`: новый маршрут в `build/`, прежняя редакция в
  `build/archive/v6/`. `npm run validate` проверяет полноту переноса;
  `npm run validate:archive` — прежние правила архива.
- `npm run test:course`: Chromium проходит весь новый маршрут и поведение.
  `npm run episode:check`: отдельный полный локальный опыт, доступный по
  `/workshop/`. Скриншоты в `work/course-evidence/` и `work/episode-evidence/`.
- Проверять сборку и браузерный маршрут без BASE_PATH и с `/Learning-individual`.
  После проверки вернуть обычную сборку без префикса для локальной мастерской.
- Локальная мастерская запускается `npm run episode`, адрес
  `http://127.0.0.1:4180`; основной сайт и локальные опыты используют одну сборку.
  Данные пользователя в `.episode-state/first-service/`, их не удалять.
- `quality/curriculum-map.json` фиксирует исходные разделы и связи заданий.
  Новые объяснения написаны для 82 уроков, технические разборы прежней редакции
  сохранены в раскрываемых секциях. Шесть начальных уроков приняты в
  `quality/editorial-review.json`, полная приёмка остаётся для углублений 76 уроков; все 530 оценок повторно сверены 27 октября.
  Полная повторная вычитка и переработка
  углублений НЕ завершена: `reviewed:false` — реальное незавершённое состояние.
  Не ставить reviewed:true на основании одного существования цитаты.
- Свежих протоколов нового курса нет: `quality/live-acceptance.json` блокирует
  выпуск. Старые протоколы сентября подтверждают только прежние опыты.
- Proxmox `10.30.90.40` разрешён пользователем для любых учебных изменений,
  но последняя проверка TCP/22 дала тайм-аут. Не превращать недоступность стенда
  в основание прекратить независимую редакционную работу.
- Не представлять проверку структуры, сохранённый отчёт или модель оборудования
  как завершённую редактуру, свежее действие на стенде или аппаратное испытание.

## Продолжение 2026-10-27

- Основные цепочки остальных 76 уроков переписаны в
  `content/course/editorial/linux.json` и `remaining.py`; предметные схемы —
  `diagrams.json`. Отрисовка: `python scripts/apply-editorial.py`, затем
  `python scripts/revise-assessments.py`. Это не старый `work/author-course.mjs`.
- Все 530 заданий имеют новые прямые объясняющие секции. Явные исправления и
  решения редактора — `assessment-corrections.json`: все 530 оценок сверены,
  250 исправлены. Полная редактура сохранённых углублений остаётся незавершённой. Не объявлять первые три пункта целиком
  выполненными на основании новых блоков и структурного валидатора.
- 45 гостевых сценариев: `scripts/practice/author_catalog.py` → `catalog.json`.
  Ещё один — `proxmox_backup.py` на хосте. Прочитать README этой папки перед
  запуском. Нельзя enroll рабочий WSL или хост Proxmox как одноразового гостя.
- Локальные проверки используют временную фикстуру без enrollment хоста.
  Команды через WSL Ubuntu с `-u root`: `test_cli.py uset` и
  `test_runner.py --all --user uset --output <путь-к-логу>`.
  Состояние: 30 сценариев прошли два варианта; 15 недоступны; Proxmox-backup
  не испытан. Краткий протокол: `quality/practice-readiness.json`.
- В WSL есть чужой процесс на 18081: не останавливать. Фикстуры используют
  собственные порты; исполнитель отказывает при занятом порте.
- Отчёты новой практики имеют отдельную схему, SHA-256 исполнителя, attempt,
  variant и контрольную сумму. Это проверка целостности, не аттестация. Старые
  результаты импортируются только как история. Источник и личную заметку
  `.episode-state/first-service/` не удалять и не перезаписывать.
- Браузерный обход ждёт `body[data-course-ready="true"]`: статический текст
  появляется раньше упражнений. Старый отчёт новой практики перепроверяется
  при открытии по attempt, варианту и SHA-256 текущего исполнителя.
