# Пробный эпизод

- Запуск из корня репозитория: `npm run episode`, адрес `http://127.0.0.1:4180`.
- Проверка поведения: `npm run episode:check`. Нужны Playwright и Chromium;
  используется общий `scripts/browser-launch.mjs`. Скриншоты и JSON-доказательства
  сохраняются в игнорируемом `work/episode-evidence/`.
- Пользовательские данные в `.episode-state/first-service/`. Проверка использует
  отдельный временный каталог; не очищать данные учащегося при отладке.
- Сервис — отдельный процесс, вход обращается к нему настоящим HTTP-запросом.
  Сохранять это свойство: доступность нельзя заменять флагом в интерфейсе.
- Это проба формата, не часть статической сборки учебника. Время прохождения
  и сохранение навыка человеком пока не измерены. Объяснения пользователя
  сохраняются для обсуждения, их смысл автоматически не оценивается.
