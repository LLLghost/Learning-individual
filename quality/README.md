# Критерии следующего выпуска

`coverage-map.json` связывает каждый оцениваемый вопрос, шаг сценария, вопрос стендовой работы и вариант мини-тренажёра с конкретным разделом книги. `npm run validate` проверяет наличие всех 530 записей, существование раздела и принадлежность раздела нужному модулю. Для записи с `reviewed: true` дополнительно проверяется, что процитированное объяснение остаётся внутри указанного раздела.

Поле `reviewed: false` означает **кандидатную** привязку: совпадение терминов ещё не доказывает, что раздел объясняет механизм ответа. Первым проходом подтверждены 17 переписанных вопросов и 24 варианта вводного мини-тренажёра; остальные привязки ждут сверки. Текущее число показывает `npm run validate`. `npm run validate:release` намеренно завершится ошибкой, пока они не проверены. Для принятия записи нужно прочитать вопрос, правильный ответ и выбранный фрагмент главы, затем при необходимости исправить объяснение в главе или само задание и только после этого выставить `reviewed: true`.

Повторные стендовые протоколы и их проверка кабинетом находятся в `live-labs/2026-09-24/`. Техническая сверка высокой цены ошибки записана в `technical-audit.md`.
