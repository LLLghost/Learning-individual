# Критерии следующего выпуска

`coverage-map.json` связывает каждый оцениваемый вопрос, шаг сценария, вопрос стендовой работы и вариант мини-тренажёра с конкретным разделом книги. `npm run validate` проверяет наличие всех 530 записей, существование раздела и принадлежность раздела нужному модулю. Для записи с `reviewed: true` дополнительно проверяется, что процитированное объяснение остаётся внутри указанного раздела.

Все 530 привязок редакционно сверены: 148 вопросов банка, 148 шагов сценариев, 74 вопроса стендовых работ, 136 вариантов быстрых вопросов глав и 24 варианта вводного мини-тренажёра. Для каждого проверены вопрос, правильный ответ и прямое объяснение в указанном разделе. `npm run validate:release` требует ноль записей с `reviewed: false` и проверяет сохранность цитат. Новые вопросы принимаются в выпуск после такой же сверки.

Повторные стендовые протоколы и их проверка кабинетом находятся в `live-labs/2026-09-24/`. Техническая сверка высокой цены ошибки записана в `technical-audit.md`.
