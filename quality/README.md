# Критерии следующего выпуска

## Новая редакция

`curriculum-map.json` независимо учитывает все 34 исходные главы, 37 модулей,
разделы и 530 оценок. Новый маршрут содержит 82 урока и три дополнительные группы
проверок начальных понятий, по два варианта в каждой. `npm run validate` доказывает сохранность структуры
и объясняющих фрагментов. Он не проводит редакционную приёмку.

Шесть начальных уроков и три пула новых вопросов приняты в `editorial-review.json`.
Оставшиеся 76 уроков и 530 перенесённых оценок имеют `reviewed: false`: полная
повторная вычитка новых цепочек не закончена. Подробные разборы предыдущего текста
сохранены, а не объявлены заново написанными. Присваивать `reviewed: true`
можно после чтения всего соответствующего урока, его примеров и заданий.

`live-acceptance.json` требует протоколы текущего содержания и сборщика:
подготовка, первый проход, проверка отчёта, откат и повтор. Нужны протоколы
как девяти прежних работ, так и практических результатов новых ВМ-уроков.
Исторические протоколы сентября это условие не закрывают. Строгая проверка
и публикация блокируются до завершения редакционной и стендовой приёмки.

## Предыдущее издание v6

`coverage-map.json` связывает каждый оцениваемый вопрос, шаг сценария, вопрос стендовой работы и вариант мини-тренажёра с конкретным разделом книги. `npm run validate` проверяет наличие всех 530 записей, существование раздела и принадлежность раздела нужному модулю. Для записи с `reviewed: true` дополнительно проверяется, что процитированное объяснение остаётся внутри указанного раздела.

Все 530 привязок редакционно сверены: 148 вопросов банка, 148 шагов сценариев, 74 вопроса стендовых работ, 136 вариантов быстрых вопросов глав и 24 варианта вводного мини-тренажёра. Для каждого проверены вопрос, правильный ответ и прямое объяснение в указанном разделе. `npm run validate:release` требует ноль записей с `reviewed: false` и проверяет сохранность цитат. Новые вопросы принимаются в выпуск после такой же сверки.

Повторные стендовые протоколы и их проверка кабинетом находятся в `live-labs/2026-09-24/`. Техническая сверка высокой цены ошибки записана в `technical-audit.md`.
