# Возвращение к исходной идее курса — 28 октября 2026

Цель: понимать, собирать, обслуживать и восстанавливать серверную инфраструктуру.
Итог: собственная лаборатория, которую ученик способен объяснить, воспроизвести,
диагностировать и восстановить с проверкой данных. Страница с заметкой оставлена
первым ограниченным опытом с процессом, файлом и ответом клиенту.

## Изменения

- Главная, каталог, книга, README и начальная мастерская описывают общую цель.
- Переписаны шесть начальных уроков: карта системы, клиент/сервер, компьютер/ОС/
  процесс, данные, первый локальный опыт и локализация отказа.
- Все 82 урока получили индивидуальные роль в общей системе, материалы для
  инженерного журнала и задачу переноса навыка в лабораторию. Это не массовая
  замена технических объяснений: полезные механизмы сохранены.
- Десять блоков завершаются результатом лаборатории, составом материалов и
  критериями проверки. `/laboratory/` и `downloads/laboratory-plan.md` строятся из
  той же карты, что и вставки уроков. Полный план включён в печатную книгу.
- Итоговые уроки теперь требуют паспорта и воспроизведения всей лаборатории,
  разборов разных уровней отказа, независимого восстановления, проверки данных
  и передачи системы. Автоматическая проверка фиксированных опытов baseline и
  unknown-incident явно ограничена этими опытами.
- Переработаны шесть начальных вопросов с прямыми цитатами объяснений. Их
  постоянные ID, группы вариантов и позиции правильных ответов сохранены.
- Устранён общий шаблон «Страница заметок и выделенные ресурсы текущего опыта»,
  который ошибочно приписывал один объект большинству тем.
- Длинные названия блоков переносятся в меню, а не обрезаются.

Источники: `content/course/infrastructure.json`, `editorial/foundation.json`,
`editorial/foundation-assessments.json`, `editorial/infrastructure-overrides.json`.
Явная авторская сверка: `quality/infrastructure-rewrite-review.json`;
обновлённые хеши 76 уроков ссылаются на неё. Это авторская сверка, не независимое
прохождение учеником и не приёмка интегрированной лаборатории.

## Граница готовности

`npm run validate:release` действительно возвращает **exit 1**: нет стендовой
приёмки нового sourceSha256 содержания. Ограничение не обходилось; старый
sourceSha256 в приёмке не заменён новым. Локальная сборка и проверки интерфейса
проходят, публикация заблокирована. После проверки префикса восстановлена сборка
для корня; локальный сервер запущен для просмотра.

Непроверено: интегрированная итоговая лаборатория на чистых ресурсах,
независимое прохождение человеком и недоступные испытания физического оборудования.
Из предыдущего аудита остаётся известная проблема одновременного редактирования
в двух вкладках: эта переработка содержания не меняет модель хранения прогресса.
Git push и удалённая публикация не выполнялись.
