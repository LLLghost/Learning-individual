`npm run editorial:render`; проверка принятых хешей:
`npm run validate:editorial`. Тематическое соответствие старых заголовков:
`depth-map.json`. Подробные прежние объяснения остаются доступны по архивным
ссылкам. Не заменять карту переноса списком формально существующих цитат.
