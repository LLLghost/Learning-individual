# Журнал проверки ub-mode

Базовый коммит: ee4e950. Дата: 2026-10-27.

1. Прочитаны SKILL.md, README навыка и AGENTS.md проекта: определены требования и границы проверки.
2. Снят чистый git status, изучены сборка, CI, интерфейс, хранение и исполнители практики: выделены входные границы и общее изменяемое состояние.
3. Запущены исходные validate:release и validate:archive для фиксации поведения до правок; вывод сохраняется в work/ub-audit.
4. Проверены команды и MCP-инструменты: crapper/dryer/mutator не установлены. По ссылкам из README загружаются официальные исходники в изолированный work/ub-audit/tools; версии будут зафиксированы.
5. Инвентаризация worktree обнаружила записи Linux-путей. Windows считает их prunable, но это не доказывает отсутствие каталогов в WSL. До проверки файлов и владельцев очистка запрещена.
6. Установлены официальные crapper/dryer/mutator в отдельный venv. Версии закреплены SHA в summary.json; основной проект зависимостями инструментов не изменён.
7. Написан реальный HTTP-тест: русский символ разорван между кусками запроса. До исправления два отказа: `��нтон` и HTTP 500 для null. Декодирование перенесено за сбор байтов, форма JSON проверяется на входе. Тесты прошли; минимальная правка — ab90838.
8. В Chromium воспроизведена невозможность открыть урок с повреждёнными коллекциями прогресса. Извлечён граничный парсер, пригодные записи сохранены, исходник включён в резервную копию; три случая и перезагрузка проходят. Коммит 11de5cf.
9. C8 измерил полное покрытие новых модулей. Mutator в Windows отказал на symlink (WinError 1314), поэтому запуск перенесён в отдельный /tmp-каталог Ubuntu, без личной страницы и оригиналов файлов.
10. В сетевой фикстуре CLI проверки ссылок доказано чтение архива вместо действующей книги. Источник исправлен, для архива добавлен явный флаг; классификация 404/403/сети проверена. Коммит eca58af.
11. На копии протоколов изменён README: прежний verify:live ошибочно вернул успех. Добавлена сверка 40 хешей, тесты нормализации LF, точных архивных байтов, пустого реестра и выхода за каталог. Доказательства исходной приёмки не редактировались.
12. Полный прогон обнаружил мою регрессию импорта newState после извлечения парсера. Общая фабрика подключена импортом, существующий экспорт/импорт вновь проходит. Коммит 6b6ce82. Отдельная проверка повреждённого прогресса сделана совместимой с префиксом публикации.
13. Новые регрессионные тесты и verify:live включены в локальный выпуск и CI. Коммит 0fa3471. Корень и /Learning-individual прошли validate:release; после префикса восстановлена обычная сборка.
14. Повторены episode:check, validate:archive, 51 selftest скрипта стенда и 23 операции CLI в безопасной временной WSL-фикстуре. Чужой процесс на 18081 не останавливался.
15. WSL-прогон --all проверил 180 shell-фрагментов и две вариации 30 работ; 15 недоступны, отказов 0. Сохранён JSON; WSL не назван чистой Proxmox-приёмкой.

17. В двух вкладках Chromium воспроизведена потеря заметки. Дефект сохранён в отчёте как открытый P1; снято настоящее наблюдение, а не вывод из структуры кода. Массовая переделка хранения в этот аудит не включена.
18. Ubuntu подтвердила существование старых worktree и незакоммиченных bundle. Очистка не выполнялась: сохранность и принадлежность текущим задачам не доказаны.
19. Проверено совпадение SHA-256 личной страницы. Собраны исходные отказы и успешные прогоны в logs/, оформлены REPORT.md и summary.json. Пользовательские данные и исходные принятые уроки не изменялись.
