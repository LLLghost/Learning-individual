Каждый отчёт из файлов `L*.json` загружался в настоящий JavaScript кабинета через Playwright. Команда `npm run verify:live` повторно сверяет формат и все критерии, а также меняет по одному проверяемому факту или ответу и убеждается, что соответствующий критерий отклонён. Во втором прогоне получилось 50/50 принятых критериев и 50/50 отклонённых подмен. Первый прогон также прошёл все девять работ; второй использовал заново созданные рабочие каталоги, новые сертификаты и заново созданные отдельные диски LVM, RAID и ZFS. Все добавленные диски и временные юниты после прогона удалены; `eth0` VM 9001 снова имел `10.10.10.11/24`, VM 9003 показывала только исходные диски `COURSE-DISK-1` — `COURSE-DISK-4`.

Это проверка на работающем учебном стенде с чистыми ресурсами каждого опыта. Полная пересборка всех VM с нуля в этом прогоне не выполнялась. После очистки хост `10.30.90.40` перестал отвечать по сети; поэтому состояние хоста после этого момента не подтверждено повторным входом. Последний успешный вход root по ключу состоялся после ротации пароля и изменения SSH-настройки.
